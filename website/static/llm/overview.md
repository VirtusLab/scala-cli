# Scala CLI overview

Scala CLI is a command-line tool that makes it easier to compile, run, test, and package Scala code.

It can:

- compile Scala code
- run it
- package it as a JAR, or in formats such as deb, rpm, MSI, and more
- start a REPL for quick exploration
- compile and run test suites

Scala CLI supports recent Scala versions (`3.x`, `2.13.x`, and `2.12.x`). Change the Scala version with `--scala` (or `//> using scala …`).

As well as the JVM (default), Scala CLI supports Scala.js and Scala Native.

Since Scala 3.5.0, Scala CLI is the default Scala runner and ships as `scala` alongside `scalac`.
