# Website

Scala CLI product site + docs, built with [Docusaurus 3](https://docusaurus.io/), React (TypeScript), and Tailwind CSS v4.

Agent guidance: [`AGENTS.md`](AGENTS.md).

## Installation

```console
yarn install
```

## Local Development

```console
yarn start
```

## Typecheck / Build

```console
yarn typecheck
yarn build
```

## Deployment

```console
GIT_USER=<Your GitHub username> USE_SSH=true yarn deploy
```
